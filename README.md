# Lumière Booking

Hệ thống đặt phòng khách sạn chuỗi **Lumière Hotels**: Mobile App cho khách (Flutter) + Web Admin cho vận hành (Next.js) + API (NestJS, PostgreSQL).

| Thư mục / file | Nội dung |
| --- | --- |
| `design/` | Thiết kế: prototype Web Admin, bộ thiết kế Mobile — xem `design/README.md` |
| `HotelBooking_BasicDesign.docx` | Thiết kế cơ bản |
| `HotelBooking_DatabaseDesign.xlsx`, `HotelBooking_schema.sql` | Thiết kế DB (PostgreSQL 16) |
| `HotelBooking_Mockup.html` | Mockup gốc |

Nhánh: `develop` (tích hợp) · nhánh tính năng tạo từ `develop` và merge qua Pull Request.
