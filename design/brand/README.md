# Vivu Stay — Nhận diện thương hiệu

**Vivu Stay** — "vi vu" (đi chơi thong thả) + "stay" (lưu trú). Tên dễ nhớ với khách Việt, khách Nhật đọc được (ヴィヴステイ).

## Logo

| File | Dùng cho |
| --- | --- |
| `vivustay-mark.svg` | Biểu tượng (ô vuông bo góc) — avatar, sidebar admin, ô logo trong app |
| `vivustay-logo.svg` | Logo ngang trên nền sáng |
| `vivustay-logo-white.svg` | Logo ngang trên nền tối (nâu gụ `#2B1A16`, ảnh) |
| `app-icon.svg`, `png/app-icon-1024.png` | Icon app iOS / Android (vuông tràn viền — hệ điều hành tự bo góc) |
| `favicon.svg` | Favicon web admin |
| `png/vivustay-mark-512.png`, `png/vivustay-logo@2x.png` | Bản PNG cho tài liệu, slide |

**Ý tưởng:** chữ **V** nét tròn như đôi cánh "vi vu", ôm **mặt trời** vàng đồng đang lên — chuyến đi, kỳ nghỉ, sự ấm áp. Nền đỏ son là màu hành động chính của hệ thống.

## Màu

| Vai trò | Mã |
| --- | --- |
| Đỏ son (nền logo, hành động chính) | `#B42318` |
| Mặt trời | `#F2C063` |
| Chữ "Vivu" | `#2B1A16` (nền sáng) · `#FFFFFF` (nền tối) |
| Chữ "Stay" | `#B42318` (nền sáng) · `#F3B4AA` (nền tối) |

## Quy tắc

- Khoảng trống quanh logo tối thiểu bằng ¼ chiều cao biểu tượng.
- Cỡ tối thiểu: biểu tượng 16 px (favicon), logo ngang cao 24 px.
- Không đổi màu, xoay, kéo méo, thêm bóng đổ; không đặt logo đỏ lên nền đỏ.
- Chữ logo dùng **Be Vietnam Pro Bold**. Khi gửi in, chuyển chữ thành outline (vector) trong Figma/Illustrator.
